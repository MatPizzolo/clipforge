   - **No digest exists yet**, so quiet-hour alerts are held and folded at the first tick after 08:00 instead of going into a 09:00 digest.
   - **No new chat setting.** Alerts go to the posting chat, which is the owner's; an `OPS_CHAT_ID` can come if a second chat is ever wanted.

   - **A failed verify (it couldn't run) counts as a failed part and alerts**, the same as differences above 0.

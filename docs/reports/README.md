# Reports

Hand-off reports from sessions, one file per checkpoint or stop: `NNN-<stream>-<YYYY-MM-DD>.md`, where NNN is the card number. Template: `docs/templates/handoff-report.md`.

- Sessions write reports; they never edit another session's report.
- The coordinator reads the report together with the PR diff, and records what it found in `STATUS.md`.
- Reports from before 2026-09-30 exist only in the first coordinator's chat; what mattered from them is in `docs/studio/10-decision-log.md` and `docs/studio/11-owner-runbook.md` §3.

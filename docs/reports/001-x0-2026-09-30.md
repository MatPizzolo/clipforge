6. **Decisions:** log #380–#390 (card 001). Choices not written down anywhere else:
   - **Hooks run with the system `python3`** (stdlib only), not `uv run`: faster, and they work before `uv sync`.
   - **The Bash guard stays conservative inside double quotes:** `$(...)` and backticks there are treated as commands. A double-quoted string that only mentions `git push` after a `;` can be a false positive. Single-quoted text and quoted heredocs are never treated as commands.
   - **`git checkout -- <file>` is allowed;** only `checkout -- .` is blocked, as the card lists. `git tag` with no arguments, and `-l`/`--list`, are allowed (listing).
   - **The scope guard leaves paths outside the repo alone** (scratchpad, memory), except secrets files anywhere. An unknown branch prefix or a detached HEAD is denied.
   - **The Stop check ignores files in `.gitignore`** (a temporary index runs `git add -A`), and never touches the real index. It needs a **full** green `check.sh` run; a partial run doesn't write the marker.
   - **`write-card` and `review-pr` stay model-invocable** (not `disable-model-invocation`), so the coordinator can use them by name.

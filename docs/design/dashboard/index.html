ClipForge dashboard: mockups (card 009)

Static HTML: open any file in a browser, no build. Resize below 1024 px for the phone layout. The bar at the top of each page switches its states (live, empty, loading, error, stale and page-specific ones). Every name and number is fictional sample data. The design rules are in DESIGN.md; the decisions behind each page are in the spec, docs/superpowers/specs/2026-10-01-studio-s3-dashboard-design.md §7.

  • Home“Needs you” with the attention meter, then the fleet scoreboard and today's slots. States: over budget, empty, loading, error, stale.
  • Act (focused view)Where a Telegram “Open” lands: one decision, then Next. States: a spend row, a promotion, already handled, not found.
  • Accounts → CompareThe weekly hour: the 3 accounts that need you, then every account side by side.
  • Account workspaceOverview (the loop at a glance, the next rung, day N of 90), Autopilot, Style, Hooks, Activity; S3c's tabs as placeholders.
  • ReviewBatch review with the gate's answers and copy editing; the before-S2 queue manager (D8).
  • ProduceThe batch planner with its estimate and review time, the queue fillers, Jobs.
  • ResultsStats, Money and Costs on one filter row: views, winners, revenue against variable cost, programs, burn against the fleet cap, fixed subscriptions.
  • PersonasIdentity lock (3 anchors), consistency per render with the drift threshold, voice master, disclosure.
